# Roadmap

What comes next. CHANGELOG.md has what has shipped.

### Making it yours

- [ ] Homepage config import in the UI (the CLI exists)
- [ ] A setup file in YAML, to export and import everything at once
- [ ] A search box with `!` shortcuts
- [ ] iCal and CalDAV calendar widget
- [ ] Notes and to-do widget
- [ ] Several Docker hosts

### Integrations

- [ ] Portainer (several Docker hosts), Netdata and Prometheus
- [ ] UniFi and Omada, Tailscale
- [ ] Nextcloud, Paperless-ngx, Lidarr, Readarr, Prowlarr, Bazarr
- [ ] Audiobookshelf and Navidrome in Right now
- [ ] Gitea and Forgejo, Vaultwarden
- [ ] Start and stop for Proxmox guests
- [ ] Links in the Elsewhere row added from the UI
- [ ] Hardcover and Goodreads: what you are reading
- [ ] Pushover and email notifications

### Running it anywhere

- [ ] Unraid and TrueNAS app templates
- [ ] A Proxmox LXC script, and running from Node without Docker

### Polish

- [ ] Accessibility audit: keyboard paths, screen-reader labels, contrast in every theme
- [ ] Translations
- [ ] A read-only API for scripts and AI tools

Want something here sooner, or something missing? Open an issue.
