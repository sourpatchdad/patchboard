# Roadmap

What comes next. CHANGELOG.md has what has shipped.

### Making it yours

- [ ] A setup file in YAML, to export and import everything at once
- [ ] A search box with `!` shortcuts
- [ ] Several Docker hosts

### Integrations

- [ ] TP-Link Omada
- [ ] Backrest
- [ ] Kavita, Komga
- [ ] GitHub releases for the apps you run

### Running it anywhere

- [ ] Unraid and TrueNAS app templates
- [ ] A Proxmox LXC script, and running from Node without Docker

### Polish

- [ ] Accessibility audit: keyboard paths, screen-reader labels, contrast in every theme
  - Covered: Home and editor keyboard paths, focus return, cancelled drafts, theme text contrast, accessible names, narrow reflow, and forced-color graphics.
  - Remaining: a spoken screen-reader walkthrough and real browser/text-only zoom. See [Accessibility checks](ACCESSIBILITY.md).
- [ ] Translations
- [ ] A read-only API for scripts and AI tools
